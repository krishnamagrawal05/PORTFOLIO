# Krishnam Agrawal — Portfolio

Static, dependency-free portfolio built with HTML, CSS and JavaScript.

## Run
Open `index.html` in a browser, or serve the folder with any static server.

## Notes
- Replace `assets/profile.png` with the final profile image if needed. The site has a KA fallback.
- Sound is generated with Web Audio API; no audio files are required and there is no autoplay music.
- Theme and sound preferences are saved in localStorage.
- `404.html` is the custom error page.
